# ⚽ SoccerPitch
 
An ASP.NET Core MVC app for building soccer team lineups with drag-and-drop pitch interface.
 
## Features
 
- Team management (create, edit, delete)
- Player roster CRUD operations
- Interactive drag-and-drop lineup builder
- Responsive Bootstrap 5 interface
- Server-rendered Razor views
## Stack
 
ASP.NET Core MVC (C#) | Entity Framework Core | SQL Server | Bootstrap 5 | Vanilla JavaScript
